# 张哲的世界 🌍

一个关于张哲的多页面互动网站，包含 8 大功能模块。

## 📋 功能

| 页面 | 功能 |
|------|------|
| 🏠 首页 | 导航中心，展示张哲档案和即将到来的纪念日 |
| 💕 爱情测试 | 输入名字，五道问答测缘分指数，雷达图 + 情书 + 海报 |
| 🎮 大冒险 | 文字冒险游戏，扮演张哲做出选择，多结局 |
| 📅 倒计时 | 纪念日倒计时，时间线展示所有重要日子 |
| 🎨 画像馆 | Canvas 手绘头像生成器，DIY 脸型/眼睛/发型 |
| 🎵 电台 | 复古收音机风格音乐播放器，Web Audio 旋律生成 |
| 💬 留言墙 | 匿名彩色便签留言板，支持管理密码 |
| 🏆 排行榜 | 冷知识问答挑战，计时答题，本地排行榜 |
| ⚙ 编辑器 | 统一数据管理，修改档案全站同步 |

## 🔧 技术栈

- 纯原生 HTML/CSS/JS，零外部依赖
- CSS 变量主题系统 + 暗黑模式
- localStorage 数据持久化
- Canvas API 绘图（雷达图、头像、海报）
- Web Audio API 音乐播放
- GitHub Pages 部署
